## 1.1 三层结构：religion → faith → rite

1.20 把宗教拆成三层，**教义（doctrine）的承载体由 faith 改为 rite**：

| 层 | 目录 | 1.20 文件数 | 说明 |
|---|---|---|---|
| **religion**（宗教组） | `common/religion/religion_types/` | 49 | 如 `christianity_religion` |
| **faith**（信仰） | `common/religion/faith_types/` | 1（`00_faith_types.txt`，+4867 行） | 具体信仰；1.20 起**信条本体迁至 `tenet_types/`** |
| **rite**（仪轨） | `common/religion/rite_types/` | 3 | **1.20 新增**；`00_rite_types` / `01_christian_heresy` / `02_mainline` |

配套新增目录：`rite_icons/`、`rite_names/`、`tenet_types/`（2）、`doctrine_category_types/`（1）、`doctrine_group_types/`（1）；`holy_site_types/` 新增 `01_dynamic_holy_site_types.txt`（动态圣所）。
旧的 `doctrine_types/30_core_tenets.txt`（−4234 行）**整份删除**，信条迁移到 `tenet_types/00_tenet_types.txt`。

`rite_types/_rite_types.info` 原文要点：

> *"If this is a faith's scripted main Rite, these are the faith's effective core tenets; do not duplicate them in the faith type."*
> *"Rite doctrines override parent-religion and faith doctrines from the same doctrine group. Faith doctrines from otherwise unfilled groups are added to the instantiated main Rite."*

即：**信仰的主仪轨承载其 core tenets 与多数 doctrines**。

## 1.2 教义读取：`faith` → `rite` ⚠ 必读

| 旧写法（1.19） | 新写法（1.20） | 1.19 用量 | 1.20 用量 |
|---|---|---|---|
| `faith = { has_doctrine = <doctrine> }` | `rite = { rite_has_doctrine = <doctrine> }`（角色**自身**仪轨）<br>`faith = { main_rite = { rite_has_doctrine = <doctrine> } }`（该信仰的**脚本主仪轨**） | 91 处 | **0 处** |
| `faith = { trait_is_sin = <trait> }` | `rite = { trait_is_sin_rite = <trait> }` | — | — |
| `faith = { has_doctrine_parameter = <p> }` | **不变**（`has_doctrine_parameter` 在 1.20 仍有 149 个文件在用） | — | — |

**两种新写法的语义差别**（选型要点）：

- `rite = { ... }` —— 取**角色当前所属仪轨**。角色改宗/改仪轨后会随之变化，适合"这个人自己遵循什么"的判定。
- `faith = { main_rite = { ... } }` —— 取**该信仰的脚本主仪轨**，全信仰一致。适合"这个信仰整体主张什么"的判定。

**仍然有效、不必改的宗教触发器**（1.20 用量实测）：
`has_doctrine_parameter`(149 文件)、`faith_hostility_level`(147)、`faith_hostile_level`(89)、`faith_astray_level`(62)、`is_holy_site_of`(51)、`faith_fully_accepted_level`(23)、`domicile_faith`(15)、`has_accolade_parameter`(10)、`is_religious_war`(2)。

## 1.4 与压力系统的接口：`stress_and_fulfillment_impact`

1.20 新增组合效果，把"缓解压力"**同时**记为"灵性满足"，并按特质归属；旧的单纯 `stress_impact = { ... }` / `add_stress` **仍然有效**（`stress_impact` 在 1.20 仍有 37 个文件在用）。

```paradox
# common/scripted_effects/00_stress_effects.txt → rakish_brothel_night_effect
if = { limit = { has_trait = lustful }
	stress_and_fulfillment_impact = { lustful = major_stress_impact_loss } }
else_if = { limit = { has_trait = rakish }
	stress_and_fulfillment_impact = { rakish = major_stress_impact_loss } }
else = { add_stress = major_stress_impact_loss }
```

## 1. 目标与范围

### 1.1 设计目标

围绕「储位是否已定」这一变量，把**参与意愿**、**内斗手段指向**、**党羽诉求**三条链路串成一个自洽闭环：

1. **统一收敛逼立储 / 共治的落地逻辑**：合法继承人 → 立储（可建则建对应共治）；非合法继承人 → 只能取得官职 / 摄政型共治（摄政 / 维齐尔 / 草原摄政）。
2. **储位影响参与意愿**：未立储 → 角逐积极性提升；已立储 → 下降。
3. **储位影响内斗指向**：已立储后，竞争者更倾向把手段（栽赃 / 下毒 / 谋杀）指向储君。
4. **子嗣数量影响手足意愿**：君主已有 ≥2 名有继承权子女时，其兄弟姐妹参与意愿下降、已参与者倾向退场。

### 1.2 需求总览

| # | 需求 | 章节 |
|---|---|---|
| 1 | 逼立储 / 共治的统一收敛（含 0520 由「请立共治」改版为「上疏请立储」） | §2 |
| 2 | 已立储 / 未立储 → 参与角逐意愿的加减 | §3 |
| 3 | 已立储 → 内斗手段向储君偏置 | §4 |
| 4 | 君主 ≥2 有继承权子女 → 手足抑制与退场 | §5 |

### 1.3 已定口径（本文件为唯一出处）

| 项 | 口径 |
|---|---|
| **合法继承人** | `ftr_court_is_legitimate_heir_of_trigger { HEIR = X }`（求值域：君主）= 主头衔继承顺位上的**非私生、未被剥夺继承权**者。此为「有继承权的子女 / 亲属」的统一判据，性别法因素由主头衔继承顺位自然体现 |
| **已立储** | `ftr_court_realm_has_crown_prince_trigger`（求值域：君主）= 存在太子共治（`has_diarchy_type = ftr_diarchy_crown_prince`）**或** `exists = designated_heir` |
| **被逼立共治者的初始天平** | **一律 40**（共治型与官职 / 摄政型统一），脚本内直接内联字面量 `40` |
| **主动立储的初始天平** | 仍为 `ftr_diarchy_crown_prince_voluntary_initial_swing_value`（10），不属「被逼」 |
| **中华霸主硬限制** | 中华政体统治者若持中华霸主头衔（`tier_hegemony`），`grand_secretariat` 宰相共治**常驻**，故永远无法再建共治 ⇒ 该情形下逼立只能落地为「指定继承人」，不建共治。此为原版硬限制，本 mod 不打破、不新增分支 |
| **数值书写** | 简单数值就地内联字面量；仅跨文件复用或复杂公式才抽 `script_values`（AGENTS §6.2） |

## 2. 逼立储 / 共治的统一收敛

### 2.1 唯一落地关节

`ftr_court_establish_champion_coregency_effect`（`common/scripted_effects/ftr_court_struggle_effects.txt`）是**唯一**的落地入口，求值域 = 君主，参数 `CHAMPION` = 被拥立者。结构：

| 步 | 条件 | 动作 |
|---|---|---|
| 前置 | champion 存在 且 `ftr_court_champion_eligible_diarch_trigger` | 否则整段跳过 |
| ① 立储 | champion 为合法继承人（`ftr_court_is_legitimate_heir_of_trigger`） | 若将建太子共治，先 `ftr_diarchy_enforce_crown_prince_unlanded_effect`；再 `set_designated_heir`。**本步不受「有无现役共治」影响** |
| ② 建共治 | `NOT = { has_active_diarchy = yes }` | 按 ① 是否为继承人二分：<br>**继承人线**（共治型）：`may_appoint_co_emperors_trigger` → `co_emperorship`；否则 `ftr_diarchy_can_start_crown_prince_trigger` → `ftr_diarchy_crown_prince`；否则 `may_appoint_co_monarchs_trigger` → `co_monarchy`；**均不满足则只留 ① 的储位**<br>**非继承人线**（官职 / 摄政型）：`government_is_nomadic` → `nomad_regency`；否则 `may_appoint_viziers` → `vizierate`；否则 `regency` |
| ② 收尾 | `has_active_diarchy = yes` | `set_diarch = champion`；`set_diarchy_swing = 40`；天平偏移通知；若最终为太子共治 → 再补 `enforce_crown_prince_unlanded`（幂等）+ `ftr_diarchy_sync_crown_prince_contest_effect`（触发 0700） |

**顺序约束**：太子线必须先 `enforce_crown_prince_unlanded` 再 `set_designated_heir`（否则引擎重算继承会把刚写入的指定清掉，见 03 §2.2）。收尾时若最终为太子共治，再补一次留守约束（幂等）与 01 角逐接线，使储君入局、其余竞争者收到去留询问。

### 2.2 消费者收编

| 消费者 | 位置 | 收编后 |
|---|---|---|
| 0520 党羽逼宫 | `events/ftr_court_struggle_events.txt` 选项 a | 直接调本关节，由其内部分流 |
| 0220 共治请愿 · 继承人线 | `ftr_court_struggle_effects.txt` | 直接调本关节（不再自行判继承人） |
| 0220 共治请愿 · 非继承人线 | 同上 | **删除**，收编进 ② 的非继承人分支 |

### 2.3 0520 改版：由「请立共治」→「上疏请立储」

- **触发扩展**：情形一 limit 由 `NOT = { has_active_diarchy = yes }` 改为 `NOT = { ftr_court_realm_has_crown_prince_trigger = yes }`。情形二（逼宫退位）**保持原判定且优先**，不受新条件影响。
- **选项 a（允准）**：调 `ftr_court_establish_champion_coregency_effect` → 烈度**回落** −20；被拥立者及其全体党羽对君主好感 **+30**。
- **选项 b（拒绝）**：被拥立者及其全体党羽对君主好感 **−60**，并按 35% 推进结仇；烈度 **+20**。
- **文案**：`.t` / `.desc` / `.a` / `.b` 全套改写为「上疏请立储」口径，双语成对。
- **派发**：`on_action/ftr_court_on_actions.txt` 低烈度档那行的 trigger 同步改为 `NOT = { story_owner ?= { ftr_court_realm_has_crown_prince_trigger = yes } }`。

### 2.4 废弃常量

以下常量随收敛失去复用价值，**内联并删除**：

- `ftr_diarchy_crown_prince_imposed_initial_swing_value`
- `ftr_court_backer_demand_initial_swing_value`
- `ftr_court_petition_regency_initial_swing_value`

## 4. 已立储 → 内斗手段偏置储君

在 `ftr_court_strife_slander_effect`（`ftr_court_struggle_effects.txt`）内，victim 抽取阶段加一层定向判定：

1. 若君主已立储、储君在 `ftr_court_participant_list` 内、且非本次 actor ⇒ 以 `random = { chance = 30 }` 决定是否**定向储君**为 victim；未命中则走原随机抽取。
2. 若 victim 为储君，重手段（0320 下毒 / 0430 谋杀）在手段分派中的权重适度上调（内联 +15），避免储君过于高危。
3. 事件 0320.a / 0430.a 的 `ai_chance` 追加 `modifier = { add = 10  victim 为储君 }`。

**判据**：新增 `ftr_court_strife_victim_is_crown_prince_trigger`（求值域：victim）= `ftr_diarchy_is_crown_prince_trigger = yes`。

## 5. 君主 ≥2 有继承权子女 → 手足抑制与退场

### 5.1 计数口径

`ftr_court_has_two_eligible_children_trigger`（求值域：君主）：以 `any_child = { count >= 2 ... }` 判定，逐名过 `ftr_court_children_eligible_heir_relative_trigger` —— 即「有继承权的子女」，口径 = `ftr_court_is_legitimate_heir_of_trigger`（主头衔继承顺位上的非私生 / 未被剥夺者；性别法由继承顺位本身体现）。

### 5.2 意愿抑制（软性，不动入口层）

| 事件选项 | 加成 |
|---|---|
| 0230.a（入局） | `this` 为君主手足 **且** 君主已有 ≥2 有继承权子女 ⇒ `−25` |
| 0230.b（拒绝） | 同条件 ⇒ `+25` |

### 5.3 已入局者的退场

**复用事件 `ftr_court_struggle.0700`**，把触发源从「立太子」扩展为「储位已定 **或** 君主已有 ≥2 有继承权子女」：

- 新增 effect `ftr_court_ask_siblings_withdraw_effect`（story 域）：君主满足 `ftr_court_has_two_eligible_children_trigger` 时，遍历 `ftr_court_claimants` 中「为君主手足」者，以变量传参 + `days = 2` 派发 0700（沿用 0700 既有的「变量 + 延迟 + trigger 守卫」范式）。
- 节流：君主获 `ftr_court_sibling_withdraw_checked` flag，防止重复派发。
- 0700 的文案改为通用口径（「有人已占先机，你是否退出竞争」），使两条触发源共用同一事件而不歧义。

## 7. 验收标准

1. 君主无指定继承人时，党羽规模达标即可派发 0520；允准后**储位被写入**，且条件具备时建立对应共治、天平为 **40**。
2. 被拥立者为非合法继承人时，只能取得 `regency` / `vizierate` / `nomad_regency`，**不写储位**。
3. 中华霸主：0520 允准后只写储位、不建共治（宰相共治常驻，② 被自然拦下）。
4. 立储后，0230.a 的入局意愿明显下降；内斗事件中储君被针对的频次高于其他竞争者，但重手段权重不失控。
5. 君主子女数跨过 2 后，其在局手足收到 0700 并倾向退场（走 `ftr_court_leave_contest_effect`，双名单一致）。
